# MedAgent-RL：一周复现与 Mind Agent 融合计划

这一周要完成三件事：先看懂项目，再复现 SFT 和 GRPO，最后把训练后的医生模型接入 Mind Agent。

## 第一天：熟悉项目和数据

先弄清楚整个项目解决什么问题，以及医生、患者和评价模型分别负责什么。然后检查 SFT、强化学习和测试数据，理解一条病例在训练过程中如何被使用。

当天的目标是能说清楚项目的整体流程，确认训练环境、数据和基础模型都准备好了。

## 第二天：复现 SFT

理解 SFT 如何用带有推理过程的问诊数据训练医生模型。先用少量数据跑通训练，再完成一次正式的 LoRA 微调，并确认模型能够正常保存和推理。

当天的目标是得到自己的 SFT 模型，并理解 SFT 为什么是后续强化学习的冷启动。

## 第三天：看懂多轮问诊环境

重点理解医生如何提问、患者如何根据隐藏病例回答、对话状态如何更新，以及系统如何判断继续问诊还是结束诊断。

同时检查奖励设计，弄清楚正确诊断、有效提问、重复提问、格式错误和问诊轮数分别如何影响奖励。

当天的目标是跑出完整的问诊轨迹，并能解释每一步的状态、动作和奖励。

## 第四天：复现 GRPO

理解同一个病例如何生成多条问诊轨迹，系统如何比较这些轨迹并计算优势，最后如何只更新医生模型。

先用小规模配置完成一次真实训练，确认奖励、优势、损失和模型参数都发生了正常变化，再根据集群资源扩大训练规模。

当天的目标是得到自己的强化学习模型和完整训练日志。

## 第五天：评测训练效果

使用同一套测试数据对比基础模型、SFT 模型和强化学习模型。

重点比较诊断质量、建议质量、平均问诊轮数、重复提问、格式错误和对话完成率，同时保留典型成功案例和失败案例。

当天的目标是判断 SFT 和 GRPO 分别带来了什么提升，而不是只看训练损失。

## 第六天：接入 Mind Agent

把训练后的医生模型作为独立的问诊能力接入 Mind Agent。医生模型负责多轮追问和最终诊断，Mind Agent 继续负责安全分诊、会话管理、RAG、ECG 和前端交互。

接入时保持两个项目独立，通过统一接口传递对话历史、患者回复和工具结果。高风险情况继续由原有安全流程处理，不交给强化学习模型。

当天的目标是让 Mind Agent 能调用医生模型完成一次完整的多轮问诊。

## 第七天：端到端验收

从患者输入开始，完整跑通安全分诊、多轮追问、工具调用、最终诊断和结果展示。

最后整理训练记录、模型、评测结果、成功案例、失败案例和演示流程。

当天的目标是得到一个可以复现、可以比较、可以演示的完整项目。
